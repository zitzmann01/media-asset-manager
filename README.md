# Media Asset Manager

Eine kleine Spring-Boot-Anwendung zur Verwaltung von Medien-Assets
(Bilder und Video-Links) mit REST-API.

## Funktionen
- Assets anlegen, lesen, ändern und löschen
- Suche nach Titel und Autor
- Automatische Tests

## Technik
Java, Spring Boot, Spring Data JPA, H2-Datenbank, JUnit

## Geplant
Login, Docker, KI-generierte Alt-Texte, Monitoring mit OpenTelemetry
